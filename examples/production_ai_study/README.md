# 真实生产空间 AI 补充实测

先完成 `docs/PRODUCTION_SUITE_AUDIT.md` 的审查与定向修复。协议 `protocol.json` 在生成程序和读取新测试性能前封存；旧研究和旧已见测试不恢复。

本轮有界范围：7 个生产任务、每任务一个独立开发 Shape 和测试 Shape、单个冻结 seed。Random、SMAC RF、KT DE、真实小模型 B、27B 生成程序 C0/C1 比较相同完整权威配置空间。H800 五任务的所有方法均处在同一个 1.7B 权重常驻、合作静默资源上下文；4090 两个 GemLite 任务比较 Random/SMAC/KT/C0/C1，不宣称该机器已部署 B。两机器结果不作跨设备混排。

C0 在 7 个开发任务各揭示最多8点；C1 只收到 C0 自己的开发反馈（每任务最佳2/最差1及失败计数），最多两次真实模型调用。两版程序均须逐字审查、SDK契约通过、保存源码SHA并冻结，才打开测试。每方法每测试任务16次揭示，失败和精确缓存命中都占预算，最多640次测试揭示；独立验收和原生默认专家调用另计。

B 是显式完整静态 grammar 变体：真实模型 logits 选择，每个可行配置都在 grammar 内，已揭示点排除；不是512点池或启发式代选，也不代表任意大空间都适用。本轮不做模型大小消融。C 由模型产生完整 Searcher，不手改模型代码、不把 SDK 兼容修复当作智能提升。生成失败、重复提议、编译与数值失败全部保留。

`work.py` 只组合现有 `asset_search.search_case`、Runner、SpaceView、ExperimentStore 和本地模型客户端。运行需要固定源代码、私有模型 manifest、原生组件路径和获准空闲GPU；私有 launch plan 和恢复状态在 `artifacts/PRODUCTION_FOLLOWUP_CURRENT.json` 所指目录。每个新阶段均经原空卡包装器和共同串行锁，不能直接绕过准入调用脚本。

本轮是一组有限、单seed的实测，不估计总体胜率、不声称全局最优。原生默认内置调优成本单列，不能伪装成等16点预算。模型加载/生成、空间构造、提议、编译、验收、稳定执行、缓存及总墙钟分开报告；共享编译缓存的成本不是独立冷启动成本。官方 API 调用仍为0。
